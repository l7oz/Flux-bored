# مستخدم فلوكس كورد · FluxCord User

`user.png` — صورة الشارة. تظهر تلقائياً لكلّ عضو في فلوكس كورد، بجانب شارة رتبته إن كانت له رتبة.

`members.json` — بصمات الأعضاء (SHA-256، بلا معرّفات مكشوفة).

**تُوحَّد ولا تنكمش**: من دخل خادم فلوكس كورد مرّةً بقيت شارته وإن غادر. هذا مقصود — الشارة
تقول «من فلوكس كورد»، لا «في الخادم الآن». الحذف يدويّ من هذا الملفّ.
