# FluxCord badge images

FluxCord's own badge images, organized by group. Equicord and Vencord badges are **not** here —
they stay original and are loaded live from their own repos; nothing in this folder changes them.

| Folder | For | Status |
| --- | --- | --- |
| `owner/` | FluxCord owner | `owner.png` — gold ring + Flux mark |
| `admin/` | FluxCord admins | `admin.png` — red ring + Flux mark |
| `supporter/` | FluxCord supporters | `supporter.png` — purple ring + Flux mark |
| `tester/` | FluxCord testers | `tester.png` — green ring + Flux mark |
| `user/` | FluxCord users | `user.png` — blue ring + Flux mark, granted via `user/members.json` |
| `custom/` | Specific members (مخصّص) | per-member image — see `custom/README.md` |

The team list (who gets which badge) lives in `../team.json`. These folders hold the images only.
